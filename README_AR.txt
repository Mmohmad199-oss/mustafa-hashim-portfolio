طريقة الرفع من الآيفون إلى GitHub:
1. نزّل ملف ZIP وفك الضغط عنه في تطبيق "الملفات" إن أمكن.
2. افتح مستودع GitHub الخاص بالموقع من Safari.
3. اضغط Add file ثم Upload files.
4. ارفع index.html ومجلد projects بكل الصور الموجودة داخله. لا ترفع index.html وحده لأن الصور لن تظهر بدونه.
5. اضغط Commit changes.
6. إذا كانت صفحة GitHub Pages مفعّلة بالفعل، انتظر دقيقة أو دقيقتين ثم افتح رابط الموقع وحدّث الصفحة.
